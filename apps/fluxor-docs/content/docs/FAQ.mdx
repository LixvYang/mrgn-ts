- What is Fluxor?
> Fluxor is a Dapp built on Mixin Computer, dedicated to making it easier for Mixin Messenger users to access decentralized financial services.

- What features does Fluxor currently offer?
> Fluxor currently has a [lending application](https://app.fluxor.cc) that you can use by connecting your wallet through Mixin Messenger.

- What is Fluxor's technical principle?
> Fluxor currently uses the mature [MarginFi protocol](https://app.marginfi.com) on Solana to meet the lending needs of Mixin users. All lending operations are on-chain, with off-chain data plugins provided.

- How fast is Fluxor?
> Fluxor's lending operation speed depends on Mixin Computer's transaction packaging speed. Currently (2025.9.12), operations take around 3 minutes.

- How is Fluxor's security guaranteed?
> Fluxor's fund security depends on the security of the MarginFi protocol. Theoretically, as long as the MarginFi protocol is secure, Fluxor's funds are safe and guaranteed.

- Does Fluxor have its own contracts?
> No
