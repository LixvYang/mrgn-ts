# Bank type contracts

## Overview

Defines SDK-facing, DTO, and Anchor-compatible representations of marginfi bank state and configuration.

## Files

| File | Role | Function |
|------|------|----------|
| `bank.types.ts` | Domain types | Defines public bank models, configuration options, flags, and integration state. |
| `dto-bank.types.ts` | DTO types | Defines transport-safe bank representations. |
| `raw-bank.types.ts` | On-chain types | Defines Anchor-compatible raw bank and configuration layouts. |
| `index.ts` | Export surface | Re-exports bank type contracts. |
